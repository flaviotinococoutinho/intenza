# Intenza

Marketplace reverso C2B (buyer-first) para produtos físicos de nicho, onde a busca tradicional falha.

A tese: formalizar mercados que hoje vivem no informal com busca estruturada, reputação e pagamento garantido.

- O comprador publica uma **intenção de compra** com categoria (MCC / taxonomia curada) e atributos tipados.
- Vendedores mandam **propostas seladas**, com validade explícita, sem ver o preço dos concorrentes.
- O comprador compara por vários critérios (preço total, reputação, aderência ao schema, prazo) e segue para **contrato & liquidação**.

Em Go, com MongoDB, Kafka, Redis, métricas e caos de propósito.
